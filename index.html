PROJETO: CONHEÇA SEUS DIREITOS OBJETIVO Criar um site gratuito para ajudar mulheres a encontrar serviços públicos de apoio e proteção próximos de sua localização, utilizando o CEP informado. SITE PUBLICADO https://leocadeira.github.io/conheca-seus-direitos/ O site está publicado através do GitHub Pages e pode ser acessado por celular ou computador. O QUE JÁ FOI FEITO CRIAÇÃO DO SITE O projeto começou como uma página criada no Webnode. O Webnode não permitia facilmente implementar a funcionalidade necessária. Decidimos migrar a solução para HTML/CSS/JavaScript. O código foi criado e colocado em um repositório do GitHub. REPOSITÓRIO Foi criado um repositório chamado: conheca-seus-direitos O arquivo principal contém o código HTML, CSS e JavaScript do site. PUBLICAÇÃO O GitHub Pages foi configurado. Branch utilizada: main Pasta: root O site está publicado e funcionando. CAMPO DE CEP O usuário pode digitar o CEP. O CEP é formatado automaticamente no padrão 00000-000. O sistema verifica se o CEP possui 8 números. CONSULTA DO CEP O projeto utiliza a API ViaCEP para consultar o endereço relacionado ao CEP. O sistema mostra: logradouro; bairro; cidade; estado. LOCALIZAÇÃO O endereço obtido pelo CEP é convertido em coordenadas geográficas. Para isso foi utilizada a ferramenta OpenStreetMap/Nominatim. CASA DA MULHER Foi criada uma base com unidades da Casa da Mulher Carioca. O sistema calcula aproximadamente a distância entre o endereço informado e as unidades cadastradas. A unidade mais próxima é apresentada. O resultado mostra: nome da unidade; endereço; distância aproximada; telefone; horário de funcionamento; botão "Ligar"; botão "Como chegar". CRAS Também foi implementada a busca do CRAS mais próximo. Foram feitos testes com diferentes CEPs. Um problema foi identificado com alguns bairros, como Rocha Miranda. A base foi corrigida e o funcionamento foi testado novamente. TESTES O site já foi testado com diferentes CEPs. Foi confirmado que o sistema consegue encontrar Casa da Mulher e CRAS em determinados endereços. O site foi enviado para outras pessoas testarem. Até o momento, o funcionamento geral está satisfatório. Assim poderemos atualizar uma unidade sem precisar alterar toda a programação.
